# Personas { #personas }

Personas são representações arquetípicas do público-alvo, criadas a partir de dados reais extraídos de pesquisas e entrevistas. Elas personificam grupos de clientes com comportamentos, dores e motivações semelhantes.

- **Composição:** uma persona típica recebe um nome fictício, uma foto, dados demográficos, uma biografia curta, seus principais objetivos e suas maiores frustrações (*pain points*).
- **Aplicação em UX:** servem para alinhar a equipe de produto. Em vez de projetar para um genérico “público-alvo de 25-40 anos”, a equipe projeta para a “Mariana, que trabalha estudando à noite e tem pouco tempo para interfaces complexas”. Isso direciona a tomada de decisão com base na empatia.
