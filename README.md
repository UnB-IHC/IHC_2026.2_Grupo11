# A11yPocket - Grupo 11

O **A11yPocket** é um guia prático de acessibilidade digital que reúne checklists interativos, ferramentas de teste e conceitos fundamentais de Interação Humano-Computador (IHC) para apoiar o desenvolvimento de interfaces web acessíveis.

🔗 **Site do Projeto:** [A11yPocket G11](https://unb-ihc.github.io/IHC_2026.2_Grupo11/)  
📂 **Repositório GitHub:** [UnB-IHC/IHC_2026.2_Grupo11](https://github.com/UnB-IHC/IHC_2026.2_Grupo11)

---

## 📌 Visão Geral

O projeto está estruturado em duas frentes principais:

1. **Checklist Interativo**: Uma ferramenta prática contendo 75 itens de acessibilidade, divididos em 5 eixos temáticos (Gestão de Projetos, Desenvolvimento e Testes, Design, Conteúdo e Heurísticas de Usabilidade). O progresso da avaliação é salvo diretamente no navegador do usuário.
2. **Documentação de IHC e Avaliações**: 
   - Base teórica apoiada na norma brasileira **ABNT NBR 17225:2025**, nas diretrizes **WCAG 2.2 (W3C)** e no **Guia UK-Brasil**.
   - Métodos de IHC aplicados: Personas, Jornadas do Usuário, Service Blueprint, Lean UX Canvas e Design Empático.
   - **Estudo de Caso**: Relatório completo de avaliação de acessibilidade e usabilidade do portal do **Detran-DF**, englobando ferramentas automáticas (WAVE, Axe DevTools, Lighthouse), análises manuais com leitores de tela (NVDA) e testes empíricos com usuários reais.
